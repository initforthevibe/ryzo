# Ryzo — Claude Code plugin marketplace

Ryzo's open-source AI-native **operating systems** for Claude Code — the GTM, RevOps & paid-ads playbooks we run, packaged as installable plugins.

```
/plugin marketplace add initforthevibe/ryzo
/plugin install outbound-os@ryzo       # cold-outbound pipeline
/plugin install revops-os@ryzo         # RevOps operating system (16 skills)
/plugin install performance-os@ryzo    # paid-ads operating system (14 skills)
```

## Plugins

| Plugin | What it is |
|---|---|
| [**outbound-os**](https://github.com/initforthevibe/outbound-os) | The AI-native cold-outbound pipeline — company context → research → list → enrich → tier → email → send. |
| [**revops-os**](https://github.com/initforthevibe/revops-os) | Ryzo's RevOps operating system — 16 skills: lifecycle, scoring, routing, pipeline, automation, deal desk, data hygiene, dashboards, attribution, forecasting, + a delivery workflow. |
| [**performance-os**](https://github.com/initforthevibe/performance-os) | Ryzo's paid-ads operating system — 14 skills across Google, Meta & LinkedIn: platform playbooks, copywriting, conversion tracking, optimization, A/B testing, bidding, budget, creative, audit, reporting. |

*A BusinessOS umbrella is on the roadmap.*
